# Personal Progress Tracker

A simple tool to log your daily activities, track your goals, and get smart advice from Gemini AI. Built with React, TypeScript, and Vite.

## Features

- Log daily activities with time and description
- Define goals and track progress percentage
- View weekly progress chart
- Persian (Jalali) calendar support
- Gemini AI assistant for tips and planning
